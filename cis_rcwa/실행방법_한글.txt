================================================================
  CIS RCWA 시뮬레이터 — 실행 방법 (한글 안내)
================================================================

[윈도우]
  · 일반 실행:            run_windows.bat  더블클릭
  · "걸어두고 퇴근" 실행:  run_background_windows.bat  더블클릭
        - 오래 걸리는 DOE 를 걸어두고 자리를 뜰 때 사용.
        - 계산은 '서버 창'에서 돕니다. 브라우저가 꺼져도 계속됩니다.
        - 이 서버 창은 닫지 마세요(최소화는 OK). 끝나면 자동 저장됩니다.
        - 나중에 브라우저를 다시 열면 '설정' 페이지에서 자동 재접속되고,
          끝난 결과는 [💾 저장된 surrogate] 목록에서 바로 불러올 수 있습니다.

  · 처음 1회는 파이썬 패키지 자동 설치(수 분). 이후엔 바로 실행됩니다.
  · 파이썬이 없으면 https://python.org 에서 설치
    (설치 화면에서 "Add Python to PATH" 반드시 체크).

  ※ .bat 파일은 영어로만 되어 있습니다. (한글을 넣으면 윈도우 cmd 가
     코드페이지 문제로 "…은 내부 또는 외부 명령이 아닙니다" 오류를 냅니다.)

[맥 / 리눅스]
  · 터미널에서:   ./run.sh              (일반 실행)
                  ./run_background.sh   (걸어두고 퇴근)
  · 실행 권한이 없다면:  chmod +x run.sh run_background.sh

[수동 실행 (공통)]
  python app.py                 → http://127.0.0.1:8787 자동 열림
  python app.py --no-browser    → 브라우저 자동열기 없이 서버만

----------------------------------------------------------------
[사용 순서]
  1) 구조 설정(위저드) → 2) 시뮬/설정 → 3) Run
  4) 결과: QE 스펙트럼 · 점 클릭 시 원인분석/민감도 · 🎯 역설계
  · 물질(n,k)은 data/materials 폴더의 .txt 에서 읽습니다.
  · surrogate 는 out/surrogate_cache 에 자동 저장(DB)되어, 같은 구조·조건이면
    재계산 없이 즉시 재사용됩니다.
