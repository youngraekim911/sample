================================================================
  CIS Simulator — 실행 방법 (Windows)
================================================================

실행 파일은 하나입니다:

  ▶ start_windows.bat   (더블클릭)

  1) 브라우저에 로딩 화면이 뜹니다 (RGGB 사각형 스피너)
  2) 그 아래 회색 글씨로 환경 체크가 진행됩니다
       ✓ Python / numpy / pyyaml / matplotlib / torch / GPU
     - 없는 패키지는 그 자리에서 pip 로 자동 설치됩니다
     - 설치가 막힌 PC 면 무엇을 IT 에 요청해야 하는지 화면에 안내
  3) 준비가 끝나면 시작 화면으로 자동 전환됩니다

  * 별도의 설치용 bat 은 더 이상 없습니다 — 로딩 화면이 다 합니다.

----------------------------------------------------------------
"걸어두고 퇴근" 모드 (DOE 장시간 실행용)

  명령창에서:   start_windows.bat bg

  - PC 절전 방지 + 브라우저를 꺼도 계산은 계속
  - 이 검은 창만 닫지 마세요 (최소화는 OK)
  - 다음날 브라우저를 다시 열면 자동 재접속됩니다

----------------------------------------------------------------
GPU(CUDA) 관련

  - 실행하는 python 의 torch 가 GPU 를 보면 자동으로 GPU 사용
  - start_windows.bat 은 torch 가 이미 있는 python 을 우선 사용
    (기존 CUDA 환경이 그대로 유지됨)
  - 로딩 화면의 "GPU (CUDA)" 줄에서 사용/미사용을 확인할 수 있음
    ("없음 — CPU 모드" 여도 동작엔 문제 없음, 속도만 느림)

----------------------------------------------------------------
직접 실행 (터미널)

  python app.py                # 기본 (로딩 화면 → 시작)
  python app.py --no-browser   # 브라우저 자동 오픈 없이
  접속 주소: http://127.0.0.1:8787

  맥/리눅스: run.sh / run_background.sh
