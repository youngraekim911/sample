# cf_green_device — 소자 유효 n,k  (원본: cf_green.txt, 6000A 평막 투과 측정)
#
# n 은 원본 그대로. k 만 통과대역(500~560nm)에서 실측 QE 로 역산해 올렸다.
#
# 왜 필요한가 — 원본 k 는 '유리기판 위 6000A non-patterned film' 의 투과로
# 뽑은 값이다. 그 측정에서는 안료가 옆으로 산란시킨 빛도 검출기가 그대로
# 받으므로 '투과' 로 계산된다. 그런데 소자에서는 0.7um 픽셀 밖으로 나간
# 빛은 그 픽셀에서 잃는다. 평막에는 '빠져나갈 픽셀' 이 없어서 이 손실은
# 원리상 측정에 안 잡힌다. 두께를 바꾸거나 간섭을 보정해도 마찬가지다
# (간섭 보정은 오히려 k 를 낮춘다 — 확인함).
#
# 배제한 다른 원인: BRL(coverage/spacer/두께), Si 두께, nG, CF 두께,
#                   수집효율 eta0, n,k 추출 간섭오차 — 전부 안 맞음.
#
# 적분구(integrating sphere)로 산란 포함 총 소광계수를 재면 이 파일을 그
# 실측값으로 교체할 것. 그러면 역산값이 아니라 실측값이 된다.
#
# 통과대역 밖(400~480, 580~700)은 원본과 동일 — 원래 잘 맞던 구간이다.
