# v132 — 구성 3종 체계 + B 채널 원인 규명

이번 버전의 내용 두 가지:
1. **`conf/hybrid_lens_tuned.yaml` 신설** — n,k 역산 없이 허용노브(BARL TiO2,
   coverage)만으로 2.78 → **2.54%p**. 사용자 제안 전략(TiO2 얇게 + coverage↑)이
   전수탐색 최적점으로 확인됨.
2. **B 채널 원인 규명** — DTI 기각, B450/B500 은 단색 일치, 실제 적자는 B400 뿐.
   상세: `docs/Blue_DTI_검증.md`

| coverage | 0.2 (추정) | **0.35** | M1 면적비 추정 상향 — **GDS 면적비 요망** |

## tuned 성적 (nG=101, ds=2, 실측 28점)

```
전체 2.54%p   R 2.70 / G 1.86 / B 3.40   G peak 77.2 (실측 74.3)
```

주변 미세탐색(전체 오차): TiO2 0.026→2.61, 0.028→2.54, 0.030→2.52, 0.032→2.56 /
coverage 0.30→2.56, 0.35→2.54, 0.40→2.54. **2.52~2.56 평탄역**이라 0.02 차이는
의미 없음 — G peak 가 가장 낮은 (0.028, 0.35) 선택.

작동 원리: TiO2 를 얇게 하면 BARL AR 중심이 단파장으로 이동해 R 장파장
반사손실이 줄고(R 600~700 개선), 그 대가로 B 단파장이 약간 손해(−0.2).
coverage 0.35 는 R 장파장 되반사를 더 채움 — B/G 는 빛의 0.3~3%만 Si 뒤에
도달하므로 부작용 없음.

## B 채널 — 이번에 규명된 것 (Blue_DTI_검증.md 요약)

- **DTI 기각**: 트렌치 흡수 총량 2.6~3.9%(채널당 ~1%p 상한). 무손실 충전으로
  바꾸면 B450 −2.5, B500 −6.8 로 오히려 악화 — poly 도광 구속이 순기여
- **B450/B500 은 단색으로 실측과 0.1%p 이내 일치** — "B 적자"의 대부분은
  20nm 대역평균이 뾰족한 시뮬 B 피크를 깎는 아티팩트
- 실제 적자는 **B@400 −4.9 하나** (Si 흡수깊이 ~0.1µm — 표면 재결합 후보)
- **bandwidth 20nm 의 채널 모순 발견**: G@500 은 20nm 필요, B@450 은 0nm 이
  맞음. 한 장비의 FWHM 이 채널별로 다를 수 없으므로, 20nm 는 G 쪽 다른 원인
  (통과대역 소광)을 대신 흡수 중 — G 원인분석과 아귀가 맞는 독립 증거
