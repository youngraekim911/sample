# RCWA→QE 계산 사슬 적대 점검 (구조·n,k 는 옳다고 가정)

목적: "QE 가 실측과 달라야 하는 이유가 코드 버그인가" 를 적대적으로 공격.
방법: 코드 정독 + **독립 구현과의 수치 대조** (같은 코드로 같은 코드를 검증하지 않음).

## 판정 요약 — 사슬은 무결, G 격차는 코드가 아니라 모델 입력의 문제

| # | 공격 | 방법 | 결과 |
|---|---|---|---|
| 1 | **전체 사슬 절대값** | 평탄 스택(동일 물질·두께)을 RCWA 전 경로로 풀어 **독립 TMM 정확해**와 대조. TMM 은 이 점검에서 새로 구현(코드 공유 0줄), 에너지 합 1.000000 확인 | **ΔQE ≤ 0.0002** (500/520/540/560nm). R 은 4자리 일치 |
| 2 | TM 인자화(FFF) | TE/TM 분리 계산 @520 | 차 0.8%p(전체 스케일), 대칭 — 이상 없음 |
| 3 | z-적분 바이어스 | `nz_per_um` 48→96→192 | 80.004→80.000→79.992 — 수렴 |
| 4 | 가로 래스터 | downsample 4→2→1 | 80.42→80.00→79.91 — 수렴 |
| 5 | 대역 샘플링 | `n_sub` 3→7→11 | **발견 ①** (아래) |
| 6 | 심부 이중계산 | `QE_deep` 확인 | 0.000% — 투과광은 QE 에 안 들어감 (보수적, 정상) |
| 7 | 푸리에 차수 | nG 101→301 (기존) | 79.5→81.2 — 위로 수렴. 코드 버그라면 내려가야 함 |
| 8 | Wood anomaly | (앞서 발견·수정) | 560/700nm 특이점 해석적 회피 — 반영됨 |

**결론: 수렴시킬수록 G peak 는 79.9(단색·ds1) → 81+(nG↑) 로 오히려 올라간다.**
계산은 "이 구조 + 이 n,k" 의 답을 정확히 내고 있고, 그 답이 실측(74.3)과 다르다.
격차는 솔버가 아니라 입력(통과대역 소광) 쪽이라는 기존 결론이 사슬 검증으로 확정됨.

## 발견 ① — 대역평균 3점 샘플이 밴드에지에서 약간 거침 (경미)

`n_sub=3`(−10/0/+10nm 균등)은 곡률 큰 구간에서 사다리꼴 오차가 있다:

| n_sub | G@500 | G@520 |
|---|---|---|
| 3 (기본) | 70.59 | 78.80 |
| 7 | 71.24 | 79.02 |
| 11 | 71.42 | 79.07 |

- 수렴값 대비 3점은 500nm 에서 **−0.8** — "500 이 정확히 맞았다"의 일부는 샘플링 우연
- 방향은 격차를 **키우는** 쪽(수렴 시 500 도 +1.0 초과) — G 초과의 원인이 아니라 반대
- 정밀 비교 시 `measurement.n_sub: 7` 권장 (런타임 7/3배)

## 발견 ② — `cu.txt` 가 3점짜리 예시값 (경미)

`data/materials/cu.txt` 헤더에 "example n,k placeholder". 값 자체는 실제 Cu 와
근사하나(550nm 0.8/2.5 vs 실제 ~0.76/2.46) 3점 보간이다. BRL 감도가 G 에 0.4%p
이하라 이번 건과 무관하지만, **실측 Cu n,k 로 교체 권장** (R 장파장 정밀도용).
