## ① `src/materials/resolver.py` — 기능 추가 (핵심)

`materials[이름].k_floor` 를 읽어 `k = max(k, 바닥)` 을 적용합니다.
어느 경로(폴더 파일 / yaml dispersion / 상수)로 온 값이든 마지막에 한 번 적용됩니다.

**바뀐 부분 — `nk()` 를 둘로 쪼갬**

```python
# [추가]
def nk(self, name, lam):
    """물질 이름 -> (n, k) @ λ(µm). k_floor 가 있으면 마지막에 바닥을 적용."""
    n, k = self._nk_raw(name, lam)
    kf = (self.materials.get(name, {}) or {}).get("k_floor")
    return (n, max(k, abs(float(kf)))) if kf else (n, k)

# [이름만 변경] 기존 nk() 본문 -> _nk_raw() (내용 동일)
def _nk_raw(self, name, lam):
    ...
```

**진단 출력에도 표시** — `source()` 도 같은 방식으로 쪼갰습니다.

```python
def source(self, name):
    s, rng = self._source_raw(name)
    kf = (self.materials.get(name, {}) or {}).get("k_floor")
    return (f"{s} + k바닥 {float(kf):.4f}", rng) if kf else (s, rng)
```

확인:
```
>>> r.source('cf_green')
('materials 폴더 + k바닥 0.0105', (0.4, 0.7))
>>> r.source('cf_red')
('materials 폴더', (0.4, 0.7))        # 바닥 없는 물질은 그대로
```

**docstring 에 근거를 박아뒀습니다** — 왜 필요한지, 네 파장 역산값이 어떻게
한 점에 모였는지가 `nk()` 주석에 그대로 있습니다.

### 안전장치
- **물질별 opt-in** — `k_floor` 를 안 쓰면 코드 경로가 예전과 완전히 동일

- **통과대역 밖 불변** — 원래 k 가 바닥보다 크면 실측값 그대로
