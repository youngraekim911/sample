# 돌리시는 yaml 에 보정 두 줄 넣기 — Green peak 80% 해결

## 진단 결과

```
측정 대역폭 = 0nm (단색)
cf_green k 바닥 = 없음
```

→ **두 보정이 모두 빠진 상태**입니다. 이때 G peak = **79.5%** 가 나옵니다
(실측 74.3). 보고하신 "80%" 와 일치합니다.

원인은 단순합니다. 두 보정 다 `conf/hybrid_lens.yaml` 에만 적혀 있는데,
위저드가 만든 yaml 은 `materials` 를 전부 `{}` 로만 쓰고 `measurement` 블록이
아예 없습니다 (`editors/structure_wizard.html:548`).

---

## 고칠 곳 — yaml 에 두 블록 추가

```yaml
materials:
  cf_green: {k_floor: 0.0105}    # ← ① Green 만 내림
  # 나머지 물질은 {} 그대로

measurement:                      # ← ② 전 채널에 작용
  bandwidth_nm: 20
  n_sub: 3
```

## 여기서 읽히는 것 세 가지

**① `k_floor` 는 Red 를 전혀 안 건드립니다.**
(a) 와 (b) 의 Red 열이 **소수점까지 완전히 같습니다** (70.30 / 54.61 / 47.77 / 36.40).
cf_green 한 물질에만 걸리므로 당연하고, 그걸 실측으로 확인한 것입니다.

**② 대역폭은 Red 를 실측 쪽으로 옮깁니다 — 지난번 제 설명을 정정합니다.**
R@600 이 70.30 → 60.93 으로 크게 떨어지는데, **실측이 62.9** 입니다.
오차로는 +7.4 → −2.0, 평균 4.64 → 2.82.
대역폭 없이 보시던 Red 피크 70.3 이 원래 **7%p 부풀어 있던 값**이었습니다.

v127 에서 "Red 가 이상해졌다"고 느끼신 것은 이 9%p 하락 때문인데,
그 하락은 악화가 아니라 **교정**이었습니다. 원인 지목은 맞았지만
나빠졌다는 뜻으로 읽히게 쓴 것은 제 잘못입니다.

**③ 둘 다 넣는 것이 두 채널 모두에 최선입니다.**
G 평균 오차 4.26 → **0.63**, R 평균 오차 4.64 → **2.82**.

## 남는 차이 — 솔직히

두 줄을 다 넣어도 **520nm 만 +1.5%p** 남습니다 (75.81 vs 74.3).

| λ | (d) 둘 다 | 실측 | Δ |
|---|---|---|---|
| 500 | 70.13 | 70.4 | −0.27 |
| **520** | **75.81** | **74.3** | **+1.51** |
| 540 | 71.83 | 71.5 | +0.33 |
| 560 | 64.04 | 64.5 | −0.46 |

**이건 '레벨이 높은 것'이 아니라 '모양이 다른 것'입니다.** 500 / 540 / 560 은
전부 ±0.5 안에 들어오고 520 하나만 튀어나옵니다.

그래서 `k_floor` 를 더 올려서 누르면 안 됩니다 — 이웃이 같이 내려가
540 / 560 이 실측 아래로 빠집니다. 실제로 흔들어 본 결과:

| k_floor | 0 (끔) | 0.0080 | **0.0105** | 0.0130 |
|---|---|---|---|---|
| G 평균 \|Δ\| | 1.90 | 1.40 | **0.55** | 1.40 |

**0.0105 가 최소점**이고 양쪽으로 다 나빠집니다.

남은 +1.5%p 는 별개의 더 작은 원인이고, 지금은 미규명입니다.
`k_floor` 로 억지로 맞추면 다른 파장을 망가뜨리므로 그대로 두었습니다.

## 확인

```bash
PYTHONPATH=. python3 tools/check_version.py <내 구조.yaml>
```

`[3]` 항목이 이렇게 나오면 적용된 것입니다:

```
      측정 대역폭 = 20nm
  [ O ] 측정 대역폭 적용됨
      cf_green k 바닥 = 0.0105
  [ O ] cf_green k 바닥 적용됨
```

## 참고 — 대역폭이 부담되면

`bandwidth_nm: 20` 은 파장당 3회 계산이라 런타임이 3배가 됩니다.
Red 를 지금 값(부풀어 있는 쪽)으로 유지하고 싶거나 런타임이 부담이면
**① `k_floor` 만** 넣으셔도 됩니다 — Green peak 이 79.5 → 76.0 으로 내려가고
Red 는 한 자리도 안 바뀝니다.

다만 그러면 500nm 이 76.0 (실측 70.4) 으로 남습니다. CF 밴드에지라
단색 계산과 대역측정의 차이가 가장 큰 지점입니다.
