# v134 — 산란 바닥(물리 모델)으로 n,k 무수정 2.28%p (역대 최저)

v132/v133 문서를 대체합니다.

## 무엇이 바뀌었나

사용자 지시: "n,k 파일은 그대로 두고, 적분구 산란을 예측해서 물리 수식으로
코드에 넣어라" → 이미 코드에 있던 안료 산란 바닥 모델(`src/materials/resolver.py`
의 `k_floor`)을 tuned 구성에서 활성화:

```yaml
materials:
  cf_green: {k_floor: 0.0105}   # n,k 파일 무수정 — 로딩 시 k = max(k, 0.0105)
```

- **n,k 원본 파일(data/materials/*.txt)은 1바이트도 안 바뀜**
- 구조도 전부 스펙 그대로 (BARL TiO2 360Å 포함)
- tuned 가 default 와 다른 것: coverage 0.25 + 이 산란 바닥, 둘뿐

## 왜 이건 "역산 피팅"과 다른가 — 정직한 분류

| 성격 | 내용 |
|---|---|
| 물리 메커니즘 | 안료 입자 산란은 평막 투과 n,k 추출에서 원리적으로 누락됨 (산란광이 검출기로 들어가 투과로 집계). 소자(0.7µm 픽셀)에서는 옆 픽셀 손실 |
| 모양 검증 | 4개 파장(520/540/550/560)에서 서로 독립으로 역산한 필요 k 가 0.0100~0.0112 **한 점에 수렴** (±7%) — 파장별 제각각이면 억지 피팅, 한 점이면 바닥이 실재 |
| 쿠폰 투과와 부합 | 유리 정규화 쿠폰 투과 peak ~89.6%(사용자 확인 "90% 살짝 밑")와 현재 n,k 는 일치 — 즉 n,k 데이터는 옳고, 빠진 건 산란뿐 |
| 파라미터 수 | 1개 (k_floor 0.0105). 적분구 haze 실측이 오면 그 값으로 교체 |
| green 만 적용 | blue 통과대역 k=0.014 는 바닥 위라 무영향. red 는 장파장에서 시뮬<실측이라 바닥 넣을 근거 없음 (안료 종류가 달라 산란도 다름) |

## 남은 오차 — 어디가 왜

| 항목 | 크기 | 원인/필요한 것 |
|---|---|---|
| G peak @520 | +2.0 | 대역폭 20nm 가정의 잔여 + 바닥값 정밀도 — 적분구 haze + FWHM 사양이 오면 정리됨 |
| B@450 | −3.7 | 대역평균 아티팩트 (단색은 0.1 이내 일치, docs/Blue_DTI_검증.md) — FWHM 사양 필요 |
| B@400 | −3.7 | 유일한 실제 B 적자 — 표면 재결합 후보 (광학 아님) |
| 어두운 채널 | +2~5 | M1 평판거울 근사 — GDS 배선 레이아웃 필요 |
| R@700 | −4.0 | 위와 같은 뿌리 |

## 필요한 실측 (우선순위)

1. **CF 쿠폰 적분구 투과 (haze)** — k_floor 0.0105 를 실측값으로 교체 (색마다 1회)
2. **QE 장비 FWHM 사양** — bandwidth 20nm 확정/교체, B450 회복
3. **M1 GDS 면적비** — coverage 0.25 확정
4. **ILD 필름스택** — ild_eff n=1.75 확정
