# 실측으로 역산한 보정값 — 실제 스펙 확인되면 여기를 고치세요

QE 를 실측에 맞추는 과정에서, **실제 값을 모르는 4개 파라미터**를 실측 QE 로
역산해 넣었습니다. 실제 스펙이 확인되면 아래 위치만 바꾸면 됩니다.
코드는 건드릴 필요 없고 **yaml 한 곳**만 고치면 됩니다.

---

## 고칠 곳 — `conf/hybrid_lens.yaml` 세 블록

```yaml
# ── ④ CF green 통과대역 k 바닥 ────────────────────────────────
#    기본 거처는 물질 파일이다:  data/materials/cf_green.txt 의  #! k_floor 0.0105
#    yaml 에 아래처럼 적으면 그쪽이 이긴다 (0 을 적으면 끄는 뜻).
materials:
  cf_green: {k_floor: 0.0105}   # ← 선택. 안 적으면 물질 파일 값이 쓰인다

# ── ① 측정기 대역폭 ──────────────────────────────────────────
#    엔진 기본값이 20nm 다 (simulator.py QE_BANDWIDTH_NM_DEFAULT).
#    yaml 에 적으면 그쪽이 이긴다. 0 을 적으면 단색 계산(옛 동작).
measurement:
  bandwidth_nm: 20      # ← QE 측정기 반치폭(FWHM). 여기를 고치세요
  n_sub: 3              #    대역 안 샘플 수 (3=중심+양끝. 5 로 올리면 더 정밀·더 느림)

# ── ②③ 후면 반사 (BRL) ──────────────────────────────────────
stack:
  si:
    back_reflector:
      enabled: true
      material: cu          # 확인됨
      thickness_um: 0.15    # 확인됨 (1500A)
      coverage: 0.2         # ← M1 이 픽셀 면적의 몇 %를 덮는지. 여기를 고치세요
      spacer_um: 0.6        # ← Si 바닥 ~ M1 사이 ILD 두께. 여기를 고치세요
      spacer_material: sio2 # ILD 물질 (다르면 이름 바꾸고 data/materials 에 n,k 추가)
      routing_pitch_um: 0   # 0 = 픽셀 피치와 동일. M1 배선 주기가 다르면 지정
```

## 각 값의 의미와 현재 근거

| # | 파라미터 | 현재값 | 어떻게 정했나 | 확인 필요한 실제 스펙 |
|---|---|---|---|---|
| ① | `measurement.bandwidth_nm` | **20** | ±10nm 에서 R·G 오차가 **동시에 최소**. ±15nm 는 다시 악화 → 단조 노브가 아니라 뚜렷한 최소점 | QE 측정기 **반치폭(FWHM)** |
| ② | `back_reflector.coverage` | **0.2** | 1.0(통짜 거울)은 되반사광이 옆 픽셀로 퍼져 어두운 채널을 2배로 키움. 0.2/0.5/1.0 비교에서 전체 오차 최소 | 픽셀당 **M1 면적비** |
| ③ | `back_reflector.spacer_um` | **0.6** | 0(직접 접촉)이면 Si-금속 계면 Fabry-Perot 공진으로 680nm 가 660nm 보다 높아지는 비물리적 결과. 0.6 에서 해소 | Si 바닥 ~ **M1 까지 ILD 두께** |
| ④ | `materials.cf_green.k_floor` | **0.0105** | 네 파장(520/540/550/560)에서 **서로 독립으로** 역산한 필요 k 가 0.0100~0.0112 안에 모임. 0.008 / 0.013 은 둘 다 더 나쁨 | cf_green 의 **산란 포함 소광계수** (적분구 측정) |

확인된 값 (바꿀 필요 없음): 금속 = **Cu**, 두께 = **1500Å (0.15µm)**, 유전체 = **ILD**

### ④ 는 무엇인가 — 실측 n,k 를 고친 게 아닙니다

`data/materials/cf_green.txt` 는 **손대지 않았습니다.** 대신 해석 단계에서
`k = max(측정k, 0.0105)` 를 적용합니다. 통과대역 밖(k > 0.0105)은 측정값 그대로입니다.

안료계 CF 의 통과대역 소광에는 두 가지가 섞여 있습니다:

| | 잡히나 |
|---|---|
| ① 색소 흡수 | 투과 기반 n,k 측정이 잡음 |
| ② 안료 입자 **산란** | **못 잡음** — 정반사에서 빠진 빛은 '흡수'로도 '투과'로도 안 세어짐 |

②는 파장 의존이 완만해서 바닥처럼 보입니다. 측정 k(0.006~0.009)를 그대로 쓰면
필터가 실제보다 투명해져 G 봉우리가 솟습니다.

**적분구(integrating sphere)로 측정한 총 소광계수**가 있으면 그 값을 넣으시면 됩니다.
그러면 이 항목은 역산값이 아니라 실측값이 됩니다.

## 바꾼 뒤 확인하는 법

```bash
# 1) 구조가 제대로 읽혔는지 (해석된 값이 그대로 찍힘)
PYTHONPATH=. python3 tools/check_version.py conf/hybrid_lens.yaml

# 2) 층별로 빛이 어디서 깎이는지 (반사·CF·grid·Si 진입)
PYTHONPATH=. python3 tools/loss_waterfall.py conf/hybrid_lens.yaml 650

# 3) 실측 대비 QE 전체 비교 — 아래 스크립트
PYTHONPATH=. python3 tools/compare_measured.py conf/hybrid_lens.yaml
```

## 현재 정합 상태 (nG=101, downsample=1, 실측 28점)

| 조건 | 전체 오차 | 밝은 채널 | 어두운 채널 |
|---|---|---|---|
| 보정 전 | 3.40 %p | 4.05 | **2.40** |
| 대역폭만 | 3.44 %p | 4.14 | 2.36 |
| BRL 0.2 + 대역 20nm | 2.61 %p | 2.38 | 3.04 |
| **현재 (+ cf_green k바닥)** | **2.32 %p** | **1.94** | 2.89 |

`k_floor` 값을 흔들어 본 결과 (G 채널 500~580nm, 평균 절대오차):

| k_floor | 0 (끔) | 0.0080 | **0.0105** | 0.0130 |
|---|---|---|---|---|
| 평균 \|Δ\| | 1.90 | 1.40 | **0.55** | 1.40 |
| 최대 \|Δ\| | 4.07 | 3.25 | **1.47** | 2.41 |

양쪽으로 다 나빠지는 **뚜렷한 최소점**입니다 (단조 노브가 아님).

## 알려진 한계 — 이 값들을 바꿔도 안 잡히는 것

- **700nm B 어두운 채널** (시뮬 14.5 vs 실측 8.3): nG 를 301 까지 올려도 수렴하지
  않습니다 (14.6 → 20.0 → 18.7). 평판 거울 모델이 실제 M1 **배선 패턴**과 달라서이고,
  실제 레이아웃(면적비·피치·층수)이 있어야 개선됩니다.
  `routing_pitch_um` 으로 배선 주기를 넣어보는 것이 첫 시도입니다.
- **R@550 9.7 vs 3.2** 등 중간파장 crosstalk: DTI 유효매질(EMT)의 해상도 한계.
  nG 를 올리면 수렴합니다 (nG101 9.1 → nG301 4.9).
- **B@400~450 −4%p**: 원인 미규명. cf_blue 데이터나 상부 구조 쪽.
- ~~G@520/540 +3~4%p~~ → **해결됨** (④ cf_green k 바닥). 지금은 +1.5 / +0.3.

**주의** — 위 3개 보정값은 **직광(수직입사) 실측 하나**에만 맞춰져 있습니다.
사광(CRA) 조건에서는 되반사광의 경로가 달라지므로 그대로 맞는다는 보장이 없습니다.
CRA 실측이 있으면 그것으로 교차검증하는 것을 권합니다.
