## ①-2 QE 측정기 반치폭

**위치**: `conf/hybrid_lens.yaml` 맨 끝

```yaml
measurement:
  bandwidth_nm: 20      # ← QE 측정기 FWHM. 기기 스펙으로 교체
  n_sub: 3              #   대역 내 샘플 수 (3=중심+양끝, 5 로 올리면 정밀·느림)
```

**왜 필요한가**: 측정기는 단색이 아닙니다. CF 밴드에지처럼 k 가 급변하는 구간에서
단색 계산과 대역평균이 크게 갈립니다.

```
   G@500 :  단색 76.1   /   ±10nm 평균 70.4   /   실측 70.4
```

**바꿀 것**: 측정기 사양서의 **반치폭(FWHM)**. `0` 을 넣으면 단색 계산(옛 동작).

**비용 주의**: 파장당 `n_sub` 회 계산이라 런타임이 3배가 됩니다.

## ①-3 M1 면적비 (`coverage`)

**위치**: `conf/hybrid_lens.yaml` → `stack.si.back_reflector`

```yaml

  enabled: true
  material: cu          # 확정
  thickness_um: 0.15    # 확정 (1500Å)
  coverage: 0.2         # ← 역산값. 실제 M1 레이아웃 면적비로 교체
```

**트레이드오프 (실측 확인)**:

# ③ 아직 안 맞는 것 — 원인과 필요한 것

## ③-1 Red 장파장 (700nm 36.0 vs 44.0, −8.0)

**원인**: 평판 거울 모델이 실제 M1 **배선 패턴**과 다릅니다.
coverage 를 1.0 으로 올리면 R@700 은 45.0 으로 맞지만 G/B@700 이 터집니다
(위 표). 즉 "얼마나 반사하나"는 맞출 수 있어도 "어디로 반사하나"가 틀립니다.

**필요한 것**: 실제 M1 레이아웃 — 면적비 / 배선 피치 / 층수.
`routing_pitch_um` 으로 배선 주기를 넣어보는 것이 첫 시도입니다.

**대안(단순화)**: 코히런트 평판거울(`coverage` + `spacer` 2개)을 **유효 후면 반사율 1개**로
바꾸는 방법. 실물 M1 은 배선 패턴 + 그 아래 M2/M3 라 간섭이 실제로는 씻겨나가므로,
위상을 안 따지는 모델이 오히려 실물에 가까울 수 있습니다. 원하시면 구현하겠습니다.

## ③-2 R@600 (59.2 vs 62.9)

`spacer` 를 실측값으로 바꾸고 나서 −3.7 로 줄었습니다 (이전엔 +8.3).
남은 차이는 ③-1 과 같은 뿌리로 보입니다.

## ③-3 어두운 채널 crosstalk (R@550 9.6 vs 3.2)

**원인**: DTI 유효매질(EMT)의 푸리에 해상도 한계.
**확인됨**: nG 를 올리면 수렴합니다 — `nG101 8.7 → nG151 4.2 → nG301 4.9`.
**대응**: 정밀도가 필요하면 `nG` 를 151 이상으로. 계산비용이 nG^2.2 로 늘어납니다.

## ③-4 Blue 400~450 (−4 %p)

**원인 미규명.** cf_blue 데이터나 상부 구조 쪽으로 추정하나 확인 안 됨.
Green 과 같은 산란 보정을 넣으면 더 낮아져 **반대 방향**이라, 단순 적용은 안 됩니다.

# ④ 이번에 고친 코드 버그

## ④-1 Wood anomaly — 가짜 공진 (`src/sim/simulator.py`)

**증상**: `QE_G` 가 550nm 70.9 → **560nm 34.7** → 570nm 58.5 로 혼자 반토막.
TM 편광 반사가 1.7% → 56.7% 로 튐.

**원인**: 회절차수의 `kz` 가 정확히 0 이 되면 `V0` 가 특이해집니다.

```
   Λ = 픽셀피치 0.7µm × 4 = 2.8µm
   Λ/λ = 2.8/0.56 = 5.0000   ← 정확히 정수
   같은 계열: 700nm(m=4), 466.7nm(m=6), 400nm(m=7)
```

기존 가드는 `R+T>1` / 비유한만 잡는데, 이 경우는 **"에너지는 보존되는데 값만 틀린"**
가짜 공진이라 검사를 통과했습니다. 밀어낸 폭도 0.05%(0.28nm)로 너무 작아
밀어낸 값조차 여전히 깨져 있었습니다.

**수정**:
1. `_wood_free_lambda()` — 스침 조건은 층 구조와 무관하게 격자·파장·입사각·상부굴절률
   만으로 정해지므로 **solve 전에 해석적으로 판정**하고 걸리면 λ 를 0.3% 밈.
   추가 계산 비용 없음. 실제로 **유지되는 차수만** 보므로 400nm(m=7, nG=101 에서
   유지 안 됨)은 안 건드립니다.
2. 사후 가드 강화 — 한 번 밀고 끝내지 않고 λ 를 **양옆으로 같은 폭** 밀어 두 점이
   일치할 때만 채택 (±0.2% → ±0.6% → ±1.5%).

**영향이 컸던 이유**: 이 한 점의 −29.5 %p 잔차가 수집효율 최소자승 적합을 오염시켜
η0 가 0.95 → 1.00 으로 뒤집혔습니다. **"수집손실이 필요하다"는 결론 자체가 버그였습니다.**

# ⑤ 왜 Green 이 80% 였나 — 원인 정리

## 결론

**CF 의 n,k 를 "유리기판 위 6000Å non-patterned film"에서 쟀기 때문입니다.
그 측정에는 "빠져나갈 픽셀"이 없습니다.**

```
  [ 6000Å 평막 / 유리 ]              [ 0.7µm 픽셀 ]
       빛 ↓                              빛 ↓
   ┌─────────────┐                  ┌───┬───┬───┐
   │ ▪ ▪ 안료 ▪  │ ← 옆으로 산란     │ R │ G │ B │
   └─────────────┘    ↘   ↙         └───┴─┬─┴───┘
      검출기 ▔▔▔▔▔                        ↓ 옆 픽셀로 넘어감
      전부 받음 = "투과"                  = G 에선 손실
```

같은 물질인데 **기하가 달라 유효 소광이 다릅니다.** 평막을 아무리 정밀하게 재도
이 항은 원리상 안 잡힙니다.

**왜 통과대역에서만 드러나나**: 흡수가 강한 구간(400/450/600/650)에서는 산란분이
흡수에 묻혀 티가 안 나고, 통과대역(500~560)에서는 산란이 손실의 대부분이 됩니다.
그래서 필요한 보정 배율이 통과대역에만 몰립니다 (520 ×1.87, 540 ×1.48, 나머지 ×1.00).

## 배제한 후보 — 전부 실측으로 확인

| 후보 | 왜 아닌가 |
|---|---|
| BRL coverage / spacer / 두께 | G 변화폭 **0.39 %p**. 520nm 는 빛의 **2.9%** 만 Si 뒤까지 도달 |
| Si 두께 (3.85 → 5.5µm) | 700 은 맞출 수 있지만 600 이 **+12** 로 터짐 |
| nG (푸리에 차수) | 101→301 에서 79.5 → **81.2** 로 **더 올라감** = 수치오차 아님 |
| CF 두께 | 감도 **−0.9 %p / 0.1µm**. 5 %p 만들려면 0.55µm 오차 필요 |
| n,k 추출 간섭오차 | 6000Å 간섭 보정하면 k 가 **작아짐** = 방향 반대 (520 ×0.96, 540 ×0.68) |
| 수집효율 η0 | 곱셈이 아님 — 단일 η0 넣으면 전체 오차 3.26 → **3.29** 로 악화 |

Si 뒤까지 도달하는 빛의 비율 (Si 3.85µm):

| λ(nm) | 500 | 520 | 550 | 600 | 650 | 700 |
|---|---|---|---|---|---|---|
| 도달 | 1.3% | **2.9%** | 8.5% | 19.9% | 32.7% | 46.8% |

→ BRL 은 **Red 600~700 의 knob 이지 Green 의 knob 이 아닙니다.**

# ⑦ 되돌리는 법

| 되돌릴 것 | 방법 |
|---|---|
| cf_green 소자 n,k | yaml 에서 `cf_green: {src: cf_green_device}` → `cf_green: {}` |
| 측정 대역폭 | yaml 에서 `measurement:` 블록 삭제 (또는 `bandwidth_nm: 0`) |
| 후면 반사경 | `back_reflector.enabled: false` |

원본 측정 데이터(`data/materials/*.txt`)는 **하나도 수정하지 않았습니다.**
