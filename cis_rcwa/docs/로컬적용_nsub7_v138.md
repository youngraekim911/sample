# [로컬 클로드 작업지시] n_sub 3→7 — R 620~680 침하(간섭무늬 골) 해소

이 문서를 로컬 클로드에게 그대로 붙여넣으면 됩니다. 수정은 총 4개 파일,
전부 값/기대값 갱신이며 엔진 코드 변경은 없습니다.

## 배경 (왜 고치나)

- R 620~680 이 실측 대비 꺼져 보였음 (640: 55.4 vs 57.8, 660: 49.7 vs 52.2)
- 원인: 620~700nm 에서 Si(3.85µm)가 반투명 → Si 층이 에탈론이 되어
  주기 FSR = λ²/(2·n_Si·L) ≈ 10~15nm, 진폭 3~6%p 의 간섭무늬 발생.
  기존 대역폭 모델(20nm 를 **3점**으로 평균, 간격 10nm)은 이 무늬를 못 씻어서
  640/650/660 표본점이 무늬의 **골**에 걸림
- 검증: 단색 4nm 스캔에서 무늬 확인, ±10nm 무늬 평균 = 640→57.9(실측 57.8),
  660→51.9(실측 52.2) 정확히 일치
- 해법: 대역 표본을 7점(~3.3nm 간격)으로 — 무늬가 제대로 평균됨.
  실소자에서 무늬가 안 보이는 이유(다이 내 Si 두께 산포 + 측정기 대역폭)의
  수치적 등가물

## 수정 1 — conf/hybrid_lens_tuned.yaml (운영 구성)

measurement 블록의 `n_sub: 3` 을 `7` 로:

```yaml
measurement:
  bandwidth_nm: 20
  # n_sub 7: 대역 20nm 를 7점(~3.3nm 간격)으로 평균. 3점이면 Si 3.85um 캐비티
  # 간섭무늬(주기 ~10-15nm @ 620-700)가 덜 씻겨 R 640/660 이 무늬 골에 걸림.
  # 7점이면 R 장파장 침하 해소 + 밴드에지 사다리꼴 오차도 수렴(적대점검 발견①).
  # 계산시간 약 2.3배.
  n_sub: 7
```

## 수정 2 — conf/hybrid_lens.yaml (순수 예측 구성)

수정 1과 동일하게 `n_sub: 3` → `7` (같은 주석).

## 트레이드오프 / 알아둘 것

- QE 계산시간 약 **2.3배** (파장당 대역 표본 3→7). DOE/surrogate 대량 실행 시
  체감됨 — 상대비교 목적이면 n_sub 3 으로 내려도 경향은 유지됨
- 620 은 +2.8 로 약간 과함 (무늬 평균 후 남는 잔차 — M1 평판거울 근사의 몫)
- R@700 −4.4 는 별개 문제로 남음 (M1 GDS 배선 레이아웃 필요 — 기존 결론)
- 이 변경은 소자 모델이 아니라 **측정기 모델**(대역 평균 정밀도)임.
  장비 FWHM 사양이 확인되면 bandwidth_nm 자체를 그 값으로 교체할 것
