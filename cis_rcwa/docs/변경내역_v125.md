# v125 변경 내역 — 무엇을 왜 바꿨나

기준: v124 → v125. 커밋 `82341f4` · `7f4eeb3` · `522ed63`
(그 이전 v118~v124 요약은 맨 아래 부록)

한 줄 요약: **후면 반사(BRL)와 측정 대역폭을 넣어 실측 평균오차를 3.40 → 2.61 %p 로 낮췄고,
그 과정에서 실측으로 역산한 값 3개가 어디 있는지 문서로 못박았습니다.**

---

## 1. 후면 반사경(BRL)을 실제 구조대로 — `conf/hybrid_lens.yaml`

### 바뀐 것

```diff
 stack:
-  si: {material: si, thickness_um: 3.85}
+  si:
+    material: si
+    thickness_um: 3.85
+    back_reflector:
+      enabled: true
+      coverage: 0.2          # M1 면적비 (역산값)
+      material: cu           # 확정
+      thickness_um: 0.15     # 확정 1500Å
+      spacer_um: 0.6         # Si 바닥 ~ M1 ILD 두께 (역산값)
+      spacer_material: sio2
```

### 왜

Si 를 통과한 장파장 빛이 그냥 빠져나가는 모델이었습니다. 실제로는 BEOL 의 M1(Cu)에
되반사되어 Si 를 한 번 더 지나갑니다. 이게 빠져 있어서 **R 채널 600~700nm 가 실측보다
낮게** 나왔습니다.

| λ(nm) | 넣기 전 | 실측 |
|---|---|---|
| 600 | 58.9 | 62.9 |
| 640 | 47.5 | 57.8 |
| 700 | 32.6 | 44.0 |

### 왜 통짜 거울(coverage 1.0)이 아닌가

`coverage: 1.0` 으로 넣어보면 되반사광이 옆 픽셀로 퍼져 **어두운 채널이 두 배**가 됩니다.

| 조건 | R@550 | B@700 | 전체 오차 |
|---|---|---|---|
| 실측 | 3.2 | 8.3 | — |
| coverage 1.0 | 11.3 | 17.0 | 2.79 %p |
| **coverage 0.2** | **9.8** | **14.5** | **2.61 %p** |

M1 은 배선이라 픽셀 전면을 덮지 않습니다. 실제 면적비를 넣어야 하고, 몰라서 0.2 로
역산해 뒀습니다.

### 왜 spacer(ILD)가 필요한가

`spacer_um: 0` (금속이 Si 에 직접 붙음)이면 Si–금속 계면에서 Fabry–Perot 공진이 생겨
**680nm 가 660nm 보다 높아지는 비물리적 결과**가 나옵니다. 실제로는 사이에 ILD 가 있고,
0.6 µm 를 넣으면 공진 위치가 정상화됩니다.

## 2. 측정기 대역폭 반영 — `measurement` 블록 + `run_qe()`

### 바뀐 것

```diff
+measurement:
+  bandwidth_nm: 20     # QE 측정기 반치폭(FWHM)
+  n_sub: 3             # 대역 내 샘플 수
```

코드 쪽은 `src/sim/simulator.py` 에 `run_qe()` / `run_band()` 가 들어갔고,
스펙트럼·DOE·API 경로가 전부 `run_qe()` 를 거치도록 바꿨습니다
(`src/sim/runner.py`, `src/api/server.py`).

### 왜

QE 측정기는 단색이 아니라 반치폭 10~20nm 대역으로 잽니다. CF 밴드에지처럼 k 가
급변하는 구간에서는 **단색 계산과 대역평균이 크게 갈립니다.**

```
cf_green k :  490nm 0.036  →  510nm 0.010     (20nm 만에 3.6배)

QE_G@500 :  단색 75.5%  /  ±10nm 평균 70.4%  /  실측 70.5%
QE_G@550 :  단색 69.0%  /  ±10nm 평균 69.1%  /  실측 68.9%
```

550nm 는 k 가 평평해 차이가 없고, 500nm 만 어긋났던 이유가 이것입니다.
**시뮬이 틀린 게 아니라 단색 계산을 대역측정과 비교한 것**이 문제였습니다.

`bandwidth_nm: 0` 이면 `run_qe()` 는 기존 `run()` 과 완전히 동일합니다 (기본 동작 불변).

### 왜 20nm 인가

단조 노브가 아닙니다. ±10nm 에서 R·G 오차가 **동시에 최소**이고 ±15nm 는 다시
나빠집니다. 뚜렷한 최소점이 있어서 20nm 로 고정했습니다.

## 4. 새로 추가된 파일 2개

### `docs/보정값_수정위치.md`
실측으로 **역산해 넣은 값 3개**가 어디 있고 어떤 근거로 그 값이 됐는지,
실제 스펙이 확인되면 어디만 고치면 되는지를 정리했습니다.
고칠 곳은 `conf/hybrid_lens.yaml` 한 파일이고 코드는 손댈 필요 없습니다.

| # | 파라미터 | 현재값 | 확인 필요한 실제 스펙 |
|---|---|---|---|
| ① | `measurement.bandwidth_nm` | 20 | QE 측정기 반치폭(FWHM) |
| ② | `back_reflector.coverage` | 0.2 | 픽셀당 M1 면적비 |
| ③ | `back_reflector.spacer_um` | 0.6 | Si 바닥 ~ M1 ILD 두께 |

### `tools/compare_measured.py`
위 값을 바꾼 뒤 실측과 나란히 비교하는 도구.

```bash

PYTHONPATH=. python3 tools/compare_measured.py conf/hybrid_lens.yaml --ds 2 --ng 51   # 빠른 확인
```

실측 데이터는 스크립트 안 `MEASURED` 표에 박혀 있으니 제품이 바뀌면 거기를 교체하면 됩니다.

## 6. 안 잡힌 것 — 솔직히

| 증상 | 원인 | 이 3개 값으로 잡히나 |
|---|---|---|
| B@700 14.5 vs 8.3 | 평판 거울 모델 ≠ 실제 M1 배선 패턴. nG 301 까지 올려도 수렴 안 함 (14.6→20.0→18.7) | **아니오** — 실제 레이아웃 필요 |
| R@550 9.8 vs 3.2 | DTI 유효매질(EMT) 해상도 한계. nG 올리면 수렴 (nG101 9.1 → nG301 4.9) | 아니오 — nG 문제 |
| G@520/540 +3~4%p | 원인 미규명 | 아니오 |
| B@400~450 −4%p | 원인 미규명 | 아니오 |

**주의** — 위 3개 보정값은 **직광(수직입사) 실측 하나**에만 맞춰져 있습니다.
사광(CRA)에서는 되반사광 경로가 달라지므로 그대로 맞는다는 보장이 없습니다.

## 부록 — v118~v124 에서 이미 바뀐 것 (요약)

| 항목 | 내용 |
|---|---|
| **DTI 서브해상도 자동보정** | 푸리에 해상도 Δ=Λ/(2M+1) 보다 얇은 트렌치는 RCWA 가 못 봄. 유지되는 차수의 푸리에 계수를 보존하도록 폭을 넓히고 묽히는 **등가 유효매질(EMT)** 을 자동 적용. UI 설정 없음, 엔진이 판단 |
| **검출 제외 마스크는 실제 폭 유지** | EMT 로 넓힌 마스크를 QE 제외에 쓰면 G 가 55%→42% 로 무너짐. 광학 맵과 기하 마스크를 분리 |
| **면적 기반 EMT 혼합** | 1-D 폭 희석은 트렌치 교차점에서 ∫Δε 를 13% 잃음. 래스터 면적비로 교체 (∫ε 오차 0.0000%) |
| **RCWA 3.2× 가속** | `_assemble()` 분리·S행렬 캐시·order 공간 창적분(실공간 560² 재구성 제거). 결과는 6자리까지 비트동일 |
| **물질 n,k 전량 실측** | air si poly sio2 al2o3 hfox tio2 tin ti teos peox ml ml_arl cf_R/G/B |
| **`library.nk()` 가 abs(k) 반환** | TiN k 가 음수(n−ik 규약)로 들어와 **이득 매질**이 되어 에너지 발산하던 문제 |
| **η0=0.945 → 1.0 되돌림** | 그 값은 '예시 si 가 과흡수라서 생긴 겉보기 손실'을 메우던 것. 실측 si 를 넣으니 재적합 결과 η0=0.995 (보정 불필요) |
| **심부 이중계산 버그** | `qe_total = A_coll + T_deep` 인데 `A_coll` 에 이미 심부 flux 가 들어 있었음 |
| **`sio2.txt` 누락 보완** | DTI liner 를 sio2 로 쓰는 구조가 아예 안 돌던 문제 |
| **cf_green 밴드에지 촘촘 측정** | 7점 → 11점 (450~600nm 20~30nm 간격) |
